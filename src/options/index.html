WhichEnv

Indicator position

Where the indicator sits on every page. This is global rather than per group on purpose: glancing at the same corner on every site is the whole point, and that only works if it never moves. Changes apply immediately in tabs you already have open.

Page markers

Two extra ways to tell environments apart, for when the pill alone is not enough. These are the defaults for every group. Any group can override either one, under Edit.

Environment groups

A group is one site and the environments you switch between. Switching keeps the path, query string and fragment, so you land on the same page you were already looking at.

Switching

How a switch behaves by default. Cmd or Ctrl inverts it, so you always have a gesture for the other one. Shift always opens a new window.

Backup and sharing

Groups sync with your Chrome profile, but a backup is worth having, and a single group pasted to a teammate saves them setting it up by hand. Nothing is written until you have seen what an import will do.

Keyboard shortcuts

Chrome allows an extension to suggest at most four shortcuts, so the numeric jumps ship unbound. Assign them here if you switch often enough to want them.

Environment colors

Individual colors are not editable, by design. The same environment is always the same color across every group, so the mapping becomes muscle memory. What you can change is which set is in use, globally, and the mapping stays fixed inside every set. Every color is also paired with a text label and a distinct shape, so the indicator stays readable if you cannot distinguish the hues.
